# Sistema de Votación en Python

Proyecto integrador para la gestión, visualización y reinicio de votaciones desarrollado en Python como trabajo colaborativo en Git.

## 🚀 Funcionalidades y Autores

* **`registrar_voto.py`**: Permite a los usuarios seleccionar un candidato e ingresar su voto en el sistema.
  * **Autor:** [Samara]

* **`ver_resultados.py`**: Muestra el total de votos acumulados por cada opción o candidato.
  * **Autor:** [Samara]

* **`reiniciar_votacion.py`**: Limpia el contador de votos para iniciar un nuevo proceso electoral.
  * **Autor:** [Mateo]

* **`mostrar_ganador` (Mejora adicional en equipo)**: Analiza los resultados registrados y anuncia automáticamente cuál candidato obtuvo la mayoría de votos o si ocurrió un empate.
  * **Desarrollado en conjunto por todo el equipo.**
